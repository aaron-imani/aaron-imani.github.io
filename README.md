# aaron-imani.github.io

Personal website of Aaron Imani, built with the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) Jekyll theme.

- Profile, links, and site settings: `_config.yml`
- About text: `index.md`
- Publications: `_data/publications.yml` (preview images in `assets/img/publications/`)
- CV: `assets/files/CV_Aaron_Imani.pdf`

Pushes to `main` are built and deployed to GitHub Pages by `.github/workflows/deploy.yml`.

Local preview:

```sh
bundle install
bundle exec jekyll serve
```
